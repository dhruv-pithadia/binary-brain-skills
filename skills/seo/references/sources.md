# Official guidance

Use these primary references when checking a technical claim. Verify current pages and feature availability at the time of the task; a redirected or removed guide can signal that older advice is obsolete.

- [JavaScript SEO](https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics): crawling, rendering, metadata and status handling.
- [Indexing directives](https://developers.google.com/search/docs/crawling-indexing/block-indexing): noindex and crawler access.
- [Canonical URLs](https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls): duplicate signals and preferred URLs.
- [Sitemaps](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap): generation, limits and submission.
- [Structured-data policies](https://developers.google.com/search/docs/appearance/structured-data/sd-policies): truthful markup and eligibility.
- [Search documentation updates](https://developers.google.com/search/updates): current feature changes, including FAQ rich-result retirement.
- [Helpful content](https://developers.google.com/search/docs/fundamentals/creating-helpful-content): usefulness, evidence and ownership.
- [Core Web Vitals](https://developers.google.com/search/docs/appearance/core-web-vitals) and [metric thresholds](https://web.dev/articles/defining-core-web-vitals-thresholds): field metrics and measurement interpretation.

These are technical references, not guarantees of search outcomes. Consult another engine's own documentation when it is part of the user's target.
